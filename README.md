# N90 · 车内 HMI 设计

> 让车成为一间会变的房子 —— 多场景年轻家庭的车内 HMI 设计

**在线预览**：https://lansir-dev.github.io/hmi-n90-demo
**完整文档**：[hmi-n90.pdf](hmi-n90.pdf)（15 页，A4 横版）

## 这是什么

小米澎程 N90 探索版（2+2+3 七座、电动升降顶舱）的车内 HMI 课程设计。
主线是**状态可见性**：车会在不同形态间切换（顶舱 200/400/700mm、床、餐桌、外放电），
用户必须随时知道「现在是什么状态、还能不能变」。

## 设计要点

- **一屏三层**：常驻层（时间/车高/电量）→ 内容层（按模式换）→ 浮层（不换页）
- **橙色只表示可点**，状态只用绿黄红蓝，且必须带文字
- **顶舱三档是三个物理边界**：700 站直下限 / 400 抗风上限 / 200 坐直通行
- **报错必须跟着处置**：不给灰按钮，给「解除：一键收好」

- 原型为点击原型，数据为模拟值
